Your README is ready

Grab the markdown, or start a fresh profile. Publishing it takes about 30 seconds.

Publish it to your profile
  1. Create a new public repository named exactly the same as your GitHub username: your-github-username.
  2. Add the README.md file you just downloaded to the root of the repository.
  3. Commit the changes, then visit github.com/your-github-username. Your README will appear on your GitHub profile.

Example: If your GitHub username is your-github-username, your special repository must also be named your-github-username.

Set up Profile Studio automation

Your package contains the files required for the dynamic features you enabled. Copy the package contents into the root of your GitHub profile repository.

  1. Create or open your public profile repository named exactly the same as your GitHub username.
  2. Copy the downloaded package contents into the repository. Merge the .github folder if you already have workflows.
  3. If you enabled the dot-matrix portrait, keep assets/profile-studio/portrait.svg in place.
  4. If you enabled Contribution Activity or Contribution Snake, allow GitHub Actions to write to the repository and run Update Profile Studio Contribution Activity once. The generated activity graph and snake assets are published to the output branch.
  5. If you enabled DEV.to automation, keep its generated workflow and configuration alongside the other Profile Studio files.

Profile Studio only updates the dynamic assets/features you enabled. Your main README content remains yours.
